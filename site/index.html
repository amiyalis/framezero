A video is just a function of time.

Every scene is one HTML file with a pure function seek(t) that draws the exact picture for instant t. That makes every frame reproducible, reviewable as a still, and renderable at any resolution.

// scene.html: no timers, no CSS animations
const DURATION = 12.6;
function seek(t) {
  // slam the hook word in at 0.0 s
  slam($('#hook'), t, 0);
  // camera pushes into the app at 3.4 s
  C.apply($('#cam'), C.track(keys, t - 2.4));
}
# look at 4 frames in ~2 seconds
python3 kit/render.py scene.html out/q \
        --stills 0,3.5,6.6,10.9

# music + effects from math (no copyright)
python3 soundtrack.py out/track.wav

# 4K60 master, fits in ~1 GB of RAM
python3 kit/render.py scene.html out/4K.mp4 \
  --scale 2 --fps 60 --audio out/track.wav \
  --frames-dir /tmp/frames

The playbook that stops thumbs.

Learned from making a real series for a study app. Some of it was learned the hard way.

Frame 0 is the hookAll hook text is visible at t = 0, with no fade-in and no logo intro. The first frame is also your thumbnail.
Context by second 3"5 things it does · the last one is the best". It promises a payoff and opens a loop.
Interrupt every 2–4 sA new color, a zoom, a label or a sound resets attention.
Show the real productReal screens in a phone. Viewers trust UI more than adjectives.
Every motion has a soundWhoosh before cuts, impact on slams, pop on labels, coin on rewards.
A true CTA + a seamless loop"Coming soon · follow" before launch, then wipe back into frame 0.
